# 工時計時與請款回報

一個單檔 HTML 小工具，給接案、按時數計費的人使用。邊工作邊計時、記下做了哪些事，每個階段結束時自動產生可以直接貼給客戶的回報；結案時一次匯總成請款報告，並自動算出勞務報酬單的應付金額、二代健保與扣繳稅額。

不需要安裝、不需要伺服器、不需要註冊帳號。所有資料只存在你自己的瀏覽器裡，不會上傳到任何地方。

## 開始使用

下載 `index.html`，用瀏覽器（Chrome、Edge、Safari、Firefox 都可以）直接打開就能用。手機也可以。

如果這個倉庫有開 GitHub Pages，也可以直接用網址打開。不同裝置、不同瀏覽器的資料彼此獨立，換裝置時請用下面的「備份與還原」搬資料。

## 第一次使用：先填所得人資料

第一次打開時，所得人資料都是空白的，「勞務報酬單」區塊會用橘色字提醒還缺哪些欄位。

按「設定所得人資料、時薪與簽名」，填入公司名稱（報酬單表頭）、所得人姓名、身分證統一編號、工作內容、每小時金額、所得格式代號、支領方式、戶籍與通訊地址、聯絡電話。空白欄位裡的灰色字只是範例，不會被存起來。

簽名可以上傳一張白底黑字的簽名照片，程式會自動去掉白色背景並裁掉多餘留白，列印時會出現在「所得人簽名」欄。

二代健保費率、執行業務扣繳稅率和起扣金額已經預設好（2.11%、單次 20,000 元以上；10%、單次 20,010 元以上），法規調整時可以在同一個視窗修改。如果是兼職人員所得（50 類），勾選下方選項即可改成扣 5%。

## 日常流程

**計時。** 按「開始計時」，中途休息按「暫停」，回來按「繼續計時」。同一階段可以暫停很多次，每一段時間都會列在計時器下方，按錯的段落可以刪除。

**記錄工作項目。** 在「這一階段做了什麼」輸入框打字、按 Enter 新增。可以上下移動排序、編輯或刪除。

**結束並回報。** 一個階段做完後按「結束並回報」，程式會把時間與項目整理成一則回報並自動複製到剪貼簿，直接貼到 LINE 或 email 給客戶即可。格式像這樣：

```
2026/11/22 13:05-14:20
75分鐘 累計 180分鐘

調整首頁圖片位置

修改內頁字體大小
```

**手動補一筆。** 忘記計時的話，在「本期回報紀錄」按「手動補一筆」，輸入結束時間和分鐘數，開始時間會自動往回推算。每一則回報都可以再編輯，累計時間會自動重算。

**收入估算。** 「收入估算」區塊會依時薪即時顯示這一階段和本期累計的金額，並依勞務報酬單算法顯示扣除健保與稅額後的實付金額。

## 請款與結案

按「產生請款報告」會打開三個分頁：

「表格」可以複製後直接貼進 Excel、Word 或 Google 試算表，格線與欄位都會保留，也可以列印或存成 PDF。「純文字」適合貼進訊息軟體。「勞務報酬單」用本期累計時數（分鐘換算成小時，四捨五入到小數一位）乘上每小時金額，自動算出應付金額、代扣與實付，並帶入簽名。時數可以手動調整。列印時第一頁是勞務報酬單，第二頁起附上完整的工作明細。

收到款項後，按「已請款，結案歸零」，本期紀錄會移到「已結案紀錄」，累計重新從 0 開始。之後仍然可以打開舊的結案報告重新列印。

## 備份與還原

資料存在瀏覽器的 localStorage，清除瀏覽器資料、換瀏覽器或換電腦都會讓資料消失。建議每次請款前後各按一次「匯出 JSON 備份」，把備份檔存在安全的地方。

還原時按「從備份還原」選擇備份檔，可以選「覆蓋目前資料」或「合併，只補上沒有的」。

**注意：備份檔裡含有你填的身分證號碼、銀行帳號、地址與簽名，請不要上傳到公開的地方，也不要放進 git 倉庫。** 這個倉庫的 `.gitignore` 已經排除了 `*.json`，避免不小心 commit 進來。

## 隱私說明

這個工具沒有任何網路請求，不使用外部字型、統計或追蹤程式。所有計時紀錄、所得人資料與簽名都只存在你自己的瀏覽器裡。

如果你要修改程式碼再公開分享，請確認沒有把自己的個人資料寫進 `LAB_DEFAULT`，這裡的值會成為每個打開網頁的人看到的預設值。
